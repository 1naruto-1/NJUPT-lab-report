# 实验报告的结构与写法（官方格式）

依据《电子报告官方格式.docx》（已复制为 `assets/report_template.docx`）。封面的课程、学院、班级、学号、姓名、教师、学期由 `config.json` 自动填写，`--project` 填“实验项目”（最多两行，一次课做两个实验时分两行写）。

## 各部分要点

**实验目的**：2～4 条，可以和预习报告的核心目的一致。

**实验原理（或设计过程）**：
- 验证性实验：用自己的话概括原理，150 字左右，配一两个关键公式即可。
- 设计性实验（模电设计题）：写设计步骤、每一步依据的公式和元件取值的核算结果。

**实验电路图**：必须是手绘拍照，不能用截图。图上要标阻值、容值等参数；用分立器件或芯片要标管脚号。没有照片就放占位并在交付时提醒。

**实验结果和实验数据分析**（篇幅最多的部分）：
- 每个实验内容一个小标题，下面依次写数据表、波形、分析。
- 数据表按模板格式分“理论值 / 仿真值 / 测量值”三行；没做仿真就去掉仿真值那一行。
- 仿真结果：数据记在表格里，仿真波形截图要加标注（图题写明通道、档位和关键读数）。
- 实测结果：仪表读数进表格；波形放用户的示波器照片和手绘波形照片，两者都要有。
- 计算相对误差：$\delta=\dfrac{测量值-理论值}{理论值}\times100\%$，并分析主要原因（元件容差、仪器内阻和输入阻抗、读数分辨率等），只写与本次数据相符的原因。

**实验小结**：写实验现象的分析、遇到的故障和处理方法、存在的问题、改进想法和收获。具体的故障和现象必须来自用户，不知道就先问；不要编造经历。篇幅半页左右。

**附录**：放 Multisim 仿真电路截图（没有仿真就省略附录）。

## 格式规范（老师在模板中强调的）

- 图题在图下方，表题在表上方，都要有编号；编号全文连续。
- 画图规范：坐标轴写名称与单位，标原点和特殊点，注意各信号间的频率和相位关系；有关联的图不能拆到两页。
- 表格不使用任何底色或配色。
