# 预习报告的结构与写法

预习报告的目的是证明进实验室前已经理解原理、明确步骤，并且“算过了”。版式与实验报告共用官方模板，封面标题会自动写成“电工电子实验预习报告”。

## 结构（Markdown 骨架）

```markdown
# <实验名称>

## 核心目的
1．……
2．……

## 核心理论
用文字加公式说明关键定律、元器件特性、电路分析方法。

## 实验内容与预先计算
### 1. 实验内容一：<名称>
1．……（每一步做什么：怎么接线、仪器设成什么、测什么、记到哪张表）
2．……

![图1 <电路名称>手绘电路图](photos/circuit1.jpg){width=11cm}

## 理论预估
### 1. 实验内容一
计算过程……

表1 <名称>理论值与记录表
| 测量项目 | … | … |
| --- | --- | --- |
| 理论值 | … | … |
| 测量值 |  |  |

![图2 <名称>预期输出波形](figs/expected1.png){width=12cm}

## 仿真分析
（需要仿真时才写；远程实验做过就写“远程实验”并插入用户截图）
```

“多个实验内容”时，每个二级标题下按“### 1. / ### 2.”分开写。

## 各部分要点

**核心目的**：2～4 条，具体到这次要会的东西（例如“用示波器光标测量时间常数 τ”），不要空泛。

**核心理论**：只写这次实验用得上的原理。公式用 `$…$` 或独立一行的 `$$…$$`，每个公式说明符号含义和适用条件。篇幅控制在一页以内。

**实验内容与预先计算**：
- 用编号写清操作步骤，包括仪器关键设置（信号源波形/频率/幅度、示波器耦合方式与档位等）。
- 电路图用用户的手绘照片；需要自行设计的电路，先给出设计结果（元件取值），再请用户照着画。
- 照片还没有就放占位：`【待插入：<实验内容一>手绘电路图（标注各元件参数）】`

**理论预估**（预习报告的核心）：
- 每个计算写“公式 → 代入数值 → 结果（带单位）”，数值由 Python 算出。
- 把理论值放进记录表，测量值一栏留空，课上直接填写（细则要求自行设计表格记录数据）。
- 需要预期波形时用 matplotlib 生成黑白图：坐标轴名称与单位、峰值、周期、τ 或特征点都要标出；多路信号画在同一时间轴上以体现相位关系。

**仿真分析**：
- 截图来自 multisim-cli 的 `capture`：通常放一张电路图、一张或几张仪器面板图，必要时放整屏截图。
- 用 multisim-cli `sim` 的数值做“理论值 / 仿真值”对比表，并简要说明误差（例如元件模型、信号源内阻）。
- 图题写清楚通道含义，例如“图3 示波器仿真波形（A 通道 u_S，B 通道 u_C）”。

## 文风

简洁、像学生自己写的：短句、少形容词，不要“深入理解”“充分掌握”之类的套话，不要大段复述课本。
